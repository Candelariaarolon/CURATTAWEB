## Tips para las fotos

- Buscá fotos donde se vea **una sola prenda** (no outfits completos, no percheros con varias prendas).
- Fondo neutro (blanco, beige, gris) funciona mejor para el estilo old money del sitio.
- Formato vertical 3:4 idealmente (ej. 600×800px). El componente las recorta a esa proporción.
- Tamaño recomendado: 400–800 KB por imagen. Más grande hace lento al usuario.
